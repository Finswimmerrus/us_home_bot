# Couple Bot

Telegram-бот с общими задачами, списками, фильмами, путешествиями, желаниями и
заметками для двух участников пары.

## Локальный запуск на Windows

Нужен Python 3.12 или новее. Отдельный PostgreSQL для локального запуска не
требуется: по умолчанию используется SQLite, а файл `couple_bot.db` создаётся
автоматически.

1. Создайте Telegram-бота через `@BotFather` и скопируйте токен.
2. В PowerShell из каталога проекта выполните:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
Copy-Item .env.example .env
```

3. Откройте `.env` и укажите токен:

```dotenv
BOT_TOKEN=ваш_токен_от_BotFather
DATABASE_URL=sqlite+aiosqlite:///./couple_bot.db
DEFAULT_TIMEZONE=Europe/Moscow
LOG_LEVEL=INFO
```

4. Запустите бота:

```powershell
python -m app.main
```

Остановить его можно сочетанием `Ctrl+C`. Для полного сброса локальных данных
остановите бота и удалите `couple_bot.db`.

## Что хранится в проекте

- `app/` — исходный код бота. Нужен для запуска.
- `migrations/` и `alembic.ini` — миграции схемы БД. Нужны при развитии проекта
  и использовании PostgreSQL.
- `tests/` — автоматические проверки. На работу запущенного бота не влияют, но
  нужны для безопасного внесения изменений.
- `.env` — локальные настройки и токен Telegram-бота. Не публикуйте этот файл и
  не удаляйте его без сохранения токена.
- `.venv/` — установленное локальное окружение Python. Его можно пересоздать,
  но без него сначала потребуется повторно установить зависимости.
- `couple_bot.db` — рабочая SQLite-база: пользователи, пары, задачи, списки и все
  остальные данные. **Это не временный файл. Его удаление полностью сбрасывает
  данные бота.**
- `pyproject.toml` — зависимости и настройки инструментов проекта.

## Безопасная очистка

При остановленном боте можно удалять только воспроизводимые файлы и каталоги:

- `__pycache__/`, `*.pyc`, `.pytest_cache/`, `.ruff_cache/`, `.mypy_cache/`;
- `*.egg-info/`;
- старые файлы `*.log`.

Не удаляйте `.env` и `couple_bot.db`. Перед любыми работами с базой остановите
бота и создайте резервную копию:

```powershell
Copy-Item couple_bot.db couple_bot.backup.db
```

Чтобы восстановить данные, остановите бота и замените `couple_bot.db` сохранённой
копией. Файлы `*.db` намеренно исключены из Git, поэтому Git не является их
резервной копией.

## Первый вход

Отправьте боту `/start`, нажмите «Создать пару» и перешлите второму участнику
полученное приглашение целиком. В нём есть персональная ссылка: она открывает бота
и передаёт код автоматически. При первом открытии Telegram может потребовать
нажать кнопку «Запустить», после чего участник сразу присоединится к паре.

При создании задачи, назначенной партнёру, на последнем шаге можно выбрать,
отправлять ему личное уведомление или создать задачу без уведомления.

## Проверки

```powershell
python -m compileall -q app
python -m ruff check app --select E9
python -m pytest -q
```

Для PostgreSQL можно явно задать `DATABASE_URL` вида
`postgresql+asyncpg://user:password@localhost:5432/couple_bot` и применить
миграции командой `alembic upgrade head`.
